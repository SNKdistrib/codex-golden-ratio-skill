# Sources and selection

This project implements its own verification code. It does not install the packs
below or reproduce their source code or full instructions.

## God of Design

References: [layout](https://github.com/cumabozkurt/god-of-design/blob/main/skills/god-layout/SKILL.md)
and [review](https://github.com/cumabozkurt/god-of-design/blob/main/skills/god-review/SKILL.md).

Ideas retained: hierarchy before decoration, explicit grids, coherent alignment,
proximity, active whitespace and concrete evidence-based corrections.
The broader pack, style atlas, installers, generic spacing ladder and subjective
score are not imported. Multiple composition methods are not proof of golden-ratio
compliance. No external implementation code was copied.

## OrangeViolin

Reference: [golden-ratio-design.md](https://gist.github.com/OrangeViolin/53ad898cdbc8734d8bb5c6a6ddf5cec4#file-golden-ratio-design-md).

Ideas retained: the division identity, distinction between lengths and their sum,
Fibonacci approximations, practical testing and usability.
Unsupported claims of automatic comfort or discomfort are not adopted. The gist
is linked for context; its text and other game-design modules are not reproduced.
