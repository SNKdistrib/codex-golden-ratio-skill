# English

Golden Ratio Visual Design for Codex is now open source.
It combines measurable golden-ratio composition with comfortable margins,
balanced controls and a geometry verifier. It does not promise that a passing
ratio makes every design beautiful.

Try it, report a reproducible issue, fork it or contribute a pull request.
Code and documentation improvements are welcome.

https://github.com/SNKdistrib/codex-golden-ratio-skill

# Français

Le skill Nombre d'or pour Codex est maintenant open source.
Il associe composition mesurable, marges confortables, commandes équilibrées
et vérificateur géométrique. Un rapport correct ne garantit pas la beauté.

Testez-le, signalez un problème reproductible, faites un fork ou proposez une
pull request. Les améliorations du code et de la documentation sont bienvenues.
